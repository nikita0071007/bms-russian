# BMS Russian

Русскоязычное приложение для мониторинга BMS (Daly) батареи электровелосипеда LiFePO4.
Сделано Студией Gusevmade.

Тестовая версия: все функции открыты, вход без кода. Подключение к плате по Bluetooth
(служба FFF0, Modbus-кадры 0xD2, только чтение). Пока не подключено, показаны примерные данные.

APK собирается автоматически (GitHub Actions) и появляется в Releases, тег `latest`.
